### MEDIUM

**MEDIUM-1：mpmath wheel manifest 缺少 expected-sha pin**
- File: `benchmarks/scripts/fetch-benchmark.ts:819-822`
- 现状：`manifest[relativePath] = { sha256: computeSha256(content), size_bytes: content.byteLength }`，sha 是**自计算**，verifyCheckerBundle 也只检查 manifest ↔ 磁盘文件一致，没有"已知正确"常量 pin。
- 攻击面：PyPI URL 路径已是内容寻址（`13/f2/abeec…607e0/...`），URL 不变即文件不变，所以 supply-chain 风险**已经被 URL 自然防住**——这是 defense-in-depth 缺口，不是当前漏洞。
- 修复建议（顺手 / 不阻塞 close）：定义 `const BFCL_MPMATH_WHEEL_EXPECTED_SHA256 = "abeec3db71d221ccd3cd89d206be1fabf5a3ee7178862f5fba23a59607e0";` 并在 `fetchPublicBinaryWithRetry` 后 assert；或者直接复用 URL 中已含的 sha 段做 self-check。
- Confidence: 0.78（构造场景需 PyPI 主动调换文件，URL 又不变；URL 自带 sha 已经堵住。属真实但低优先级 defense-in-depth gap）。

**MEDIUM-2：scorer SIGINT/SIGTERM 转发不退出 parent，UX 与"interrupts kill the runner"预期不一致**
- File: `benchmarks/src/scorers/bfcl-v4-multi-turn.ts:206-225`
- 现状：listener 只 `child.kill(signal)`，未 `process.exit`/重抛。Node 注册 listener 即抑制默认 exit。
- 构造场景：用户在 multi-turn 评测中段 Ctrl-C → SIGINT 入 listener → child Python 被 SIGINT 杀掉 → `child.on("close")` 触发 reject(`exit ${code}: ${stderr}`) → runner.ts:242 catch 并 wrap 为 `BenchmarkRunError("score", ...)`。最终 runner 顶层会 propagate，但**首次 SIGINT 期间 parent 未 exit**，仅在 score phase boundary 处通过 throw 传出。如果 runner 被嵌入到长 lived process（Iter D mesh / web 控制面），单次 Ctrl-C 不会按 OS 默认终止 parent。
- 单 task sequential 场景下危害有限（错误最终上抛）；多 task 并发 / 嵌入 host 场景下，listener 的累积（每次 spawn 注册一对）也会触发 `MaxListenersExceededWarning`（默认 10）。
- 修复建议（建议落 R3 / E3c1b 顺手）：listener 内 forward 之后**重抛信号**（`process.removeListener(signal, ...); process.kill(process.pid, signal);`），或显式 `process.exit(130)` for SIGINT。Listener 数量也要小心——多 in-flight checker 会累积。
- Confidence: 0.85（机制可证；当前 sequential runner + 单 in-flight check + score phase 错误传播，实际危害程度处于 MEDIUM 上限而非 HIGH）。

### LOW

**LOW-1：`decodeUtf8Prefix` 在合法 `�` 末尾的退化**
- File: `benchmarks/src/scorers/bfcl-v4-multi-turn.ts:268-281`
- 构造场景：upstream JSON 输出本身合法地以 `�` 结束（罕见——checker 输出 JSON 一般 ASCII），且字节正好溢出 1MB。算法会 walk back 直到 end=0 退化为 `""`。
- 修复建议（可不做）：限制 walk back 最多 3 字节（UTF-8 一个字符上限），超出仍 reject 时返回原始 `subarray(0, maxBytes).toString("utf8")` 而非 `""`，避免极端 degrade。
- Confidence: 0.60（构造路径成立但 checker JSON 输出含 `�` 概率极低；JSON 解析也会先一步失败）。
