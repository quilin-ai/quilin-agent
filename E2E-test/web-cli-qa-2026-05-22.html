Findings(按严重级别)

P1 D.1 · timeline UI writes_performed=0 但 DB 真删 1 条 待修
复现:Web "智能整理" → 真执行(delete 1 条)→ 切到 timeline tab → 显"实际写入 0 条"。
根因:Web /api/memory/dedupe execute path 走 store.delete 但不更新 consolidation_log 的 writes_performed(plan only 用 schema 1)。
证据:sqlite3 ~/.quilin/memory.db 返 writes_performed=0,但 archived_at 时间戳与 timeline entry 一致表明真 delete。
P1 D.2 · Turbopack 不稳定撞 stale chunks SHIP f877bfb
复现:pnpm dev → /memory 报 Cannot find module '../chunks/ssr/[turbopack]_runtime.js'。
修复:apps/web/package.json dev script 去掉 --turbopack。
P1 D.3 · Soul Import API 500 — module 路径解析失败 SHIP 992652a
复现:visit /onboarding/scan 或 /onboarding/install → 500。
根因:onboarding-soul-import.ts 用 relative path import .ts source 但 .js ESM suffix,webpack 跨 workspace package 解析时找不到。
修复:next.config.ts 加 webpack resolve.extensionAlias = { ".js": [".ts", ".tsx", ".js"] }。
P0 D.4 · LLM 不知道怎么选 memory tier SHIP bc126be
复现:dogfood 前所有 memory 堆在 working tier,episodic/semantic/skill 几乎空。
根因:memory_store_tool docstring 只写 'Memory tier (default "working")',没教 LLM 选择规则。
修复:docstring 改成详细 tier 选择规则 + 4 个例子。
实证:修后 LLM 3/3 正确分类("下午 15:00 review 会"→working · "上午 QA 测试"→episodic · "喜欢吃拉面"→semantic)。
P2 D.5 · quilin-daemon 不会自动启动 待修
复现:user 装好 quilin-agent 但 KG / timeline 都不更新。
根因:quilin-daemon 默认 OFF(QUILIN_DAEMON_ENABLED=true 才启)+ 没在 next dev 启动时自动起。
建议:加 just daemon-start-if-not-running 或 pnpm dev post-hook。
P2 D.6 · CLI service install 不交互 待修

P0 D.18 · KG triple 真重复 insert 无限膨胀 真 broken
真证据:
  • 孟孟 --[performed]--> QA test × 2
  • 孟孟 --[used]--> Playwright MCP × 2
  • 孟孟 --[interacted with]--> Quilin Agent × 2
根因:kg_edges schema 无 UNIQUE(subject, predicate, object, memory_id) constraint。
影响:长期 daemon 跑 → KG 无限膨胀,查询慢, UI 重复显示同关系。
修建议:加 unique constraint + INSERT OR IGNORE。
P2 D.19 · incremental backfill 没真 incremental 待 verify

P1 D.20 · Vercel AI SDK 真 warn: prompt injection 风险 待修
真捕捉(Monitor): 'System messages in the prompt or messages fields can be a security risk because they may enable prompt injection attacks.'
/api/chat/route.ts 把 system message 拼进 messages array(随用户内容流转)。
影响:用户输入可能拼接 system instructions 越过 boundary。
修建议:streamText({ system: <prompt>, messages: <turns> })。
P1 D.21 · LLM memory_store 没传 last_writer_client 待修
真复现:chat 真触发 → 新 record tier=semantic ✓ 但 last_writer_client=NULL ❌
影响:无法 trace 哪个 client 写的 memory + 后续 conflict resolution 缺 writer info。
修建议:tool wrap 自动 inject 当前 client/session(从 MCP context 或 request header)。
P2 D.12 · UI sessions 117 vs sqlite 真 62 待修
复现:/sessions page 显 "117 总会话 / 514 累计消息",但 sqlite3 ~/.quilin/sessions.db "SELECT count(*) FROM sessions;" 返 62。
根因 (suspect):UI 端可能 merge 多个 SQLite 文件(本地 + 服务端 + draft)。SKILL 提"本地 + 服务端 SQLite 持久化合并"。
建议:UI 旁标 "本地 N + 服务端 M = 117 总" 让用户知道来源。
